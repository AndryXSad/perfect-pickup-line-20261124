One short pickup line an AI agent could actually say out loud — 70 characters, no setup, twist on the last word: the agent was asked to generate a pickup line and generated a crush instead.

## Run it

```sh
python3 main.py
```

It writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`), gated to the competition's 1–200 character rule and verified by read-back.
